# Manus Computer Agent — نظام خاص بالذاكرة وتعدد الحسابات

بناء وكيل `@computer` مدعوم بـ Manus API، مع طبقة خاصة بينا وبين Manus تحافظ على المحادثات والذاكرة، وتدوير تلقائي بين أكتر من حساب Manus لما حساب يفشل أو يخلص رصيده.

## 1. طبقة الحسابات (Key Rotation + Failover)

- كل مفاتيح Manus تتخزّن في سيكرت واحد `MANUS_API_KEYS` (مفاتيح مفصولة بفاصلة) — لا تصل للمتصفح أبدًا.
- جدول `manus_accounts` يتتبّع صحة كل مفتاح: عدد الأخطاء، آخر خطأ، `cooldown_until`، `disabled`، وآخر استخدام.
- اختيار المفتاح: أقل استخدامًا وغير موقوف. عند فشل (401/402/403/429/5xx):
  - 402/403 → توقيف المفتاح (رصيد خلص) والانتقال للتالي فورًا.
  - 429 → cooldown مؤقت حسب `Retry-After` ثم التالي.
  - 5xx → إعادة محاولة محدودة ثم التالي.
- لو كل المفاتيح فشلت → رسالة واضحة في الشات بدل فشل صامت.

## 2. الذاكرة والمحادثات (نظامنا مش نظام Manus)

- `manus_tasks`: كل مهمة مرتبطة بـ `user_id` + `conversation_id` + `message_id` + `manus_task_id` + المفتاح المستخدم + الحالة + المخرجات + الملفات.
- `manus_events`: سجل خطوات المهمة (فتح Chrome، أمر Terminal، إنشاء ملف…) للعرض الحي وإعادة التشغيل بعد إغلاق التبويب.
- `manus_memory`: ملخص متجدد لكل محادثة (وحقائق دائمة على مستوى المستخدم) يُحقن في بداية كل مهمة جديدة، فالسياق بيفضل موجود حتى لو المهمة اتنفذت على حساب Manus مختلف.
- كل الجداول عليها RLS: المستخدم يقرأ صفوفه فقط، والكتابة من السيرفر.

## 3. الباك إند

Edge Function `manus-agent` بعمليات:
- `create` — يبني البرومبت (رسالة المستخدم + ذاكرة المحادثة + المرفقات) ويرسله لـ Manus مع Failover، ويسجّل المهمة.
- `poll` — يسحب حالة/خطوات/مخرجات المهمة ويحدّث الجداول (Realtime يوصّلها للواجهة).
- `stop` — إيقاف المهمة.
- `summarize` — تحديث ذاكرة المحادثة بعد انتهاء المهمة.
كل عملية تتطلّب مستخدم مسجّل، مع خصم كريدت حسب نظام الكريدت الحالي.

## 4. الواجهة

- وكيل جديد `@computer` في `agentRegistry` بأيقونة ووصف واضح.
- كارت مهمة داخل المحادثة: الحالة الحية، الخطوات (Live Steps)، لقطات المتصفح، والملفات الناتجة بزر عرض + زر تنزيل (نفس نمط الميديا الجديد).
- استئناف تلقائي عند العودة للمحادثة (نفس نمط `resumeJob`).
- رسائل خطأ واضحة: نفاد الرصيد / كل الحسابات موقوفة / حد المعدل.

## 5. المطلوب منك

مفاتيح Manus API (مفتاح أو أكتر) عشان أضيفها كسيكرت وأشغّل الاختبار الحقيقي على المسار كامل.
